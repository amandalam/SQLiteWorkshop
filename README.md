# SQLiteWorkshop
SQLite Script files & extension binaries for the June 10th 2017 morning workshop session of [Hong Kong Open Source Conference 2017](https://hkoscon.org/2017/schedule/).

- [Presentation_Deck.pdf](Presentation_Deck.pdf): 

	The slides I presented at the conference.
	
- [create-fts-tables.sql](create-fts-tables.sql):

	SQL Scripts to create FTS virtual tables for full text search
	
- [ext-queries.sql](ext-queries.sql):

	SQL scripts to verify if the extension-functions has already been loaded successfully.

- [fix-data-types.sql](fix-data-types.sql):

	SQL Scripts to convert the numeric columns to the right data types upon importing from data source.

- [fts-queries.sql](fts-queries.sql):

	Full-text search query example SQL scripts.

- [links.txt](links.txt):

	Links for downloading data resources required for the workshop.

- [queries.sql](queries.sql):

	SQL Queries as illustrated in the workshop.

- [stats-queries.sql](stats-queries.sql):

	Statistical query examples.

- [stopwords.txt](stopwords.txt):

	A list of stopwords that should be excluded from the full-text search

- [workshopdesc.txt](workshopdesc.txt)

	The original description of the workshop I submitted for the Hong Kong Open Source Conference 2017.
